# ContextIQ Client

Web frontend for ContextIQ, built on the [server](../server/README.md) REST API.

**Status: in progress.** Implemented phase by phase following the
[frontend implementation plan](../docs/FRONTEND_IMPLEMENTATION_PLAN.md) (§13).
Phase 1 (scaffold, theme, shadcn/ui) is complete.

## Stack

| Concern | Choice |
|---|---|
| Framework | Next.js 16 (App Router, Turbopack), React 19, TypeScript (strict) |
| Styling | Tailwind CSS v4 (CSS-first config in `src/app/globals.css`) |
| UI components | shadcn/ui (`radix-nova` style on Radix UI primitives), lucide-react icons |
| Toasts | sonner (shadcn `sonner` component) |

Planned for later phases: Zustand (state), React Hook Form + Zod (forms),
react-markdown + remark-gfm + rehype-highlight (answer rendering).

## Getting started

Requires Node.js 20.9+ and the backend running on `http://localhost:8000`
(see [server/README.md](../server/README.md)).

```bash
cd client
cp .env.example .env.local   # NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
npm install
npm run dev                  # http://localhost:3000
```

| Script | Purpose |
|---|---|
| `npm run dev` | Development server |
| `npm run build` / `npm start` | Production build / serve |
| `npm run lint` | ESLint |
| `npm run type-check` | TypeScript, no emit |

The backend's CORS defaults already allow `http://localhost:3000`.

## Conventions

- **shadcn/ui components** live in `src/components/ui/` and are generated with
  `npx shadcn@latest add <component>`. Edit them in place; don't hand-roll replacements.
- **Theme**: dark mode only for now. Use semantic Tailwind classes (`bg-background`,
  `bg-card`, `text-muted-foreground`, `bg-primary`, `text-success`, `text-warning`,
  `text-destructive`, `text-info`), never raw palette classes such as `bg-slate-900`.
  Tokens are defined in `src/app/globals.css`.
- **Config**: only `NEXT_PUBLIC_API_BASE_URL`. Never put secrets in `NEXT_PUBLIC_*` variables.
- `AGENTS.md` is generated by Next.js (re-added by `next dev`) and points coding
  agents at the version-matched docs in `node_modules/next/dist/docs/`.
